# GeeyoouUI 演进路线（对标 Qt）

本文件是**迭代交付的总纲**。每一轮迭代的产出（PRD / 架构决策 / 实现 / 测试 / 安全结论 / 验收）落在 `docs/iterations/NN-<name>.md`，代码按文件分别提交。

## 交付流水线

```
产品团队规划 → 研发专家团队实现 + 单元测试 → 功能测试 → 安全团队
（内存安全 / 代码规范）→ 研发返工 → 产品验收 → 下一轮
                      ↑
        遇到分歧或阻塞：研发中心决策团队会议（rnd-cto + 架构 + CEO 委员会）
```

- 每轮迭代结束：**代码按文件分别提交**，并生成本轮迭代文档
- 质量门：测试不通过 或 安全有高危 → 不得宣布完成
- 决策升级：跨迭代影响、推翻既有架构决策、依赖引入 → 召开决策会议

## 迭代规划

依赖顺序排列。每轮是一次完整流水线。

### R1 —— 核心对象层
对象树与生命周期、属性系统、信号槽生命周期绑定、事件分发。

- `core/Object`：父子所有权、确定性析构、`findChild`、弱引用
- 属性系统：按名字读写、变更通知、编译期注册（**无 moc**）
- 信号槽：**自动断连**——当前 `Signal` 无生命周期绑定，`Window` / `AppWindow` / `ShowcaseWindow` 都在析构里手工 `disconnect()`，这是已经踩到的坑
- 事件：`Event` 基类 + 类型 id、事件过滤器、传播控制
- **测试基建**：本仓库目前没有任何单元测试，本轮建立测试 target

**风险**：触及全部 32 个控件。验收标准必须包含"现有 showcase 全页面不回归"。

### R2 —— 布局引擎
推翻 §4「v1 用绝对坐标」。

- 盒模型、`SizePolicy`、min/preferred/max
- `BoxLayout` / `GridLayout` / `FormLayout`
- 与绝对坐标**共存**，允许逐页迁移

**验收**：showcase 页面改用布局后，窗口缩放不再依赖 `ScrollArea` 兜底。

### R3 —— 文本引擎（Blend2D 之上）
- BiDi 双向文本、字体回退链、精确命中测试、行内预编辑（补上 §3.8 的缺口）

**验收**：中英阿混排正确、命中测试精确到字形、IME 内联预编辑可用。

### R4 —— 表格
- 单元格合并、行内编辑、单元格内 tag/chip、列宽拖拽、冻结行列、web 风格样式

**验收**：百万行虚拟化 + 合并单元格 + 编辑提交/回滚。

### R5 —— 弹出层与动效
- 溢出窗口的独立弹层（推翻 §4「弹层限制在窗口内」）、tooltip、消息对话框、drawer
- 动画曲线 / 时间轴（当前只有 30fps tick）

**验收**：tooltip 跟随光标、模态/非模态对话框、缓动动画。

### R6 —— 样式对标 Qt
- QSS 覆盖面补齐：sub-control、盒模型、padding/margin/border-image
- 剩余 21 个控件接入选择器（见 `architecture.md` §2.6 覆盖表）

**验收**：Qt QSS 常用子集可直接跑。

## 规模说明

这是**对标 Qt Core + Qt Gui + Qt Widgets** 的工作量。以上六轮不是一个会话能完成的，交付单位是**一轮一会话**。任何一轮的"完成"以测试通过 + 安全无高危 + 产品验收为准。
